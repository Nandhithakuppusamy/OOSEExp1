# Passport Automation - Document Management Module

## Technologies
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
- Multer

## Features
- Upload PDF/JPG/JPEG/PNG documents
- Store document metadata in MongoDB
- Store uploaded files in backend/uploads
- View uploaded file
- View all documents
- Verify or reject documents
- Delete documents

## API
POST   /api/documents/upload
GET    /api/documents
GET    /api/documents/:id
PUT    /api/documents/:id
DELETE /api/documents/:id

## Run
1. Install Node.js.
2. Install MongoDB Community Server and make sure MongoDB is running.
3. Open this project folder in VS Code.
4. Open Terminal.
5. Run:
   npm install
6. Start:
   npm start
7. Open:
   http://localhost:5000

For development:
   npm run dev
